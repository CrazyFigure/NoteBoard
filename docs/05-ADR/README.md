## 修订规则

- ADR 一经「已定」，**不修改正文**，要改就新开一份 ADR 并把旧的状态改为「已被 ADR-xxx 取代」。
- 需求侧的变更（如 FR-613 废弃）在 ADR 里记录成因，不在需求文档里删除历史。
