# NoteBoard 主题与设计规范

> 决策依据：[ADR-009](05-ADR/ADR-009-主题Token体系与无障碍基线.md)
> 色值来源：[KoniKee/TMD_Type-Markdown](https://github.com/KoniKee/TMD_Type-Markdown)（MIT），逐行读取自 `src/styles/globals.css`
> **本文所有对比度均为实测值**（WCAG 2.1 相对亮度算法），非估计。校验脚本见 §11。

---

## 1. 设计原则

1. **三套主题，一套结构。** 所有主题定义完全相同的变量集合，只是值不同。缺变量 = CI 失败。
2. **组件只消费语义层与组件层，不碰色板层。** 想改某个组件的颜色，改它的组件层 Token，不去动 `--accent-500`。
3. **一套 `--hljs-*` 驱动两个编辑器内核。** Markdown 代码块（lowlight）与代码文件（CodeMirror）用同一组变量，改一处两边同时变。
4. **对比度是硬约束，不是建议。** 正文 ≥ 4.5:1，功能性指示 ≥ 3:1，由单元测试锁住。
5. **身份色与功能色分离。** `--accent-500` 负责好看，`--accent-strong` 负责能看清。

## 2. Token 三层结构

```
色板层（原始色阶，组件禁止直接引用）
├── --primary-50 … --primary-900        中性色阶
├── --accent-50  … --accent-800         强调色阶
└── --success/warning/error-500/600

语义层（表达用途）
├── --editor-bg / -surface / -text / -text-secondary / -text-muted
├── --editor-border / -border-focus / -heading / -link / -accent
├── --editor-code-bg / -quote-bg / -selection
├── --accent-strong                     ★ NoteBoard 新增
├── --code-inline-bg / -inline-text
├── --code-block-bg / -block-container-bg / -block-text
└── --hljs-*（17 个）                    ★ 比 TMD 多 2 个

组件层（绑定具体组件）
├── --titlebar-* / --tab-* / --statusbar-*
├── --explorer-*                        ★ NoteBoard 新增（TMD 叫 --sidebar-*）
├── --outline-*                         ★ NoteBoard 新增
├── --cm-*                              ★ NoteBoard 新增（CodeMirror 界面）
├── --board-*                           ★ NoteBoard 新增（Excalidraw）
├── --rail-*                            ★ NoteBoard 新增（折叠把手）
├── --alert-{note,tip,important,warning,caution}-{border,bg}
└── --scrollbar-track / -thumb

尺度层（三套主题共用，不随主题变化）
├── --radius-sm/md/lg/xl                4 / 6 / 8 / 12px
├── --shadow-sm/md/lg                   亮色与暗色两组
└── --transition-fast/normal/slow       150 / 200 / 300ms ease
```

## 9. 主题切换机制

### 9.1 数据流

```
用户在设置里选主题
  ├─ settingsStore.setThemeMode('hu-po')
  ├─ applyTheme(): documentElement.dataset.theme = 'hu-po'
  │     └─ 全部颜色由 CSS 变量驱动，无需重建任何组件（NFR-106 ≤ 100ms，无闪烁）
  ├─ invoke('save_settings')
  │     └─ Rust 落盘 + emit('nb://settings-changed')  ★ 广播
  └─ 其他窗口收到广播 → applyTheme()（FR-1004）
```

### 9.2 跟随系统（FR-1002）

```ts
themeMode === 'system'
  → window.matchMedia('(prefers-color-scheme: dark)').matches
      ? settings.systemDarkTheme     // 默认 'mo-ye'
      : settings.systemLightTheme    // 默认 'chen-guang'
```

监听 `mediaQuery.change` 热切换。`systemLightTheme` 与 `systemDarkTheme` 是**两个独立设置**，用户可以选「亮色时用琥珀，暗色时用墨夜」。

### 9.3 防首屏闪烁

`main.tsx` 在 **React 渲染之前**同步读取设置并写 `data-theme`：

```ts
// main.tsx 顶部，render 之前
const cached = localStorage.getItem('nb.theme.resolved');   // 上次解析结果的缓存
if (cached) document.documentElement.dataset.theme = cached;
// 之后再异步 load_settings 校正
```

配合 `tauri.conf.json` 的 `"visible": false` + 前端就绪后 `window.show()`，做到零白屏零闪烁。

### 9.4 三个内核的适配方式

| 内核 | 机制 |
|---|---|
| **TipTap** | 纯 CSS 变量，零 JS |
| **CodeMirror** | `Compartment` 热切 `HighlightStyle` + `EditorView.theme`，二者都读 CSS 变量 |
| **Excalidraw** | `theme` prop（`'light'`/`'dark'`）+ 覆盖它的 CSS 变量（§7） |

**Mermaid 需要单独重渲染**（它把颜色烧进 SVG）：主题变化时对当前视口内的 mermaid 节点重新 `render()`。
