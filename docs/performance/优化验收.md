## 2. 实际变化（关键链路）

| 领域 | 改造前 | 改造后 |
| --- | --- | --- |
| 首屏依赖 | 壳静态导入全部编辑器+弹窗；保存/暂存链反向 import 编辑器组件 | EditorHost 按类型懒加载（kind+language 选择入口；解析路径即预取与读盘并行）；保存/暂存/搜索/工具栏全部经 core 能力注册表（editorRegistry），零编辑器组件 import |
| 启动协议 | window_ready 一次性握手（取意图+显示）；第二实例 emit 事件直接打开（订阅前丢失） | listeners-ready 握手（consumer 代际）→ 设置加载 → 壳显示 → drain 打开队列（Rust 队列权威、非破坏读取、幂等 ACK、空列表竞态覆盖）；迁移走 transferId 状态机（preparing→target-prepared→committed/aborted，不盲超时回滚） |
| 文件打开 | probe→read→register 串行 IPC；已打开文件读完全文才发现 | prepare_document 一次往返（读盘前归属查询/在途去重/blocking 读取判别）；重复打开零读盘直接激活 |
| 字体 | get_font_pack_status 同步全量 SHA（阻塞 UI 线程）；PowerShell/WPF/Add-Type 子进程枚举系统字体；全包 6 face 主动 load | SHA 移入 spawn_blocking（进程缓存+文件身份复验+generation 失效）；GDI EnumFontFamiliesExW 进程内枚举（真机测试过，剔除 SYMBOL_CHARSET 行为一致）；ensureFaces 只 load 配置引用族 |
| Markdown | 单组件同建 TipTap+CM 两内核；50ms 时间窗忽略输入；每键全文序列化 | VisualKernel 惰性挂载（source 首屏零 TipTap 实例）；同步程序事务锁；三轮重做 J2：每键只捕获不可变引用（O(1)），序列化按历史组延迟执行（跨组保留，R02 反例保持通过） |
| 会话恢复 | 每个恢复文件走完整 openDocument（读盘+编辑器预取） | 轻量描述符（零读盘零编辑器加载）；点击标签才加载；恢复不抢焦点 |
| 后台标签 | 全部 tabs 挂载编辑器（-99999 隐藏） | 活动文档 + 最近 1 个已验证可回收实例（三轮后全部类型可回收：Code/Image/diagram/infographic + Markdown/Board/Bitable/Mindmap/Drawio，各自恢复选区/滚动/视口/查看状态） |
| 历史 | 每节点存全文（≤201 节点） | 检查点+可逆补丁（每 20 组检查点；随机序列与朴素全文实现逐字等价对照 100 步通过） |
| 保存 | 各编辑器各自直接 writeDocument | 每文档串行写队列 + flush 屏障 + flush-and-compare 脏态 + 带内容证明的暂存清理（H 节时序表 8 例覆盖） |
| 目录监听 | Rust 空占位命令（无真实监听） | plugin-fs watchImmediate 中心服务（引用计数；自身写入按路径静默防自触发） |
| 壳订阅 | AppShell 订阅整个 documents Map（每次内容更新重渲染全壳） | size 下沉到 UnsupportedView/EditorHost 按 key 订阅；壳零 documents 订阅 |
| 暂存 | 任意 store 变化全量扫描 | dirty revision 队列（只暂存变化集合；5s 兜底/失焦全量保留） |
| 图表调度 | 模块单槽（后到任务覆盖前一个，不同节点渲染丢失） | docKey+nodeId 身份有界队列（同节点替换/不同节点各有结果/时间片让出） |
