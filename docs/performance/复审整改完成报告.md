## 各项整改明细

### R01 (P0) 未加载恢复标签覆盖暂存副本 ✅
- `closedWindowSession.ts`：恢复正文一律 `content: null`（空字符串彻底退出写入链）；命名文件按原路径恢复**不再标脏**（磁盘为权威基线），暂存副本保留在磁盘暂存区脱离内存管理（与原实现语义一致）；仅未命名标签（暂存路径为打开来源）进入关闭保护。恢复完成**不再 clearSession**，改为把恢复出的标签（含未加载条目的原暂存路径）重写回会话——未加载标签在进程异常退出后仍可再次恢复。
- `stagingManager.ts`：`collectDocuments` 跳过一切 lazySource 标签（自动/批量暂存绝不触碰未加载标签）；用户显式"暂存并关闭"时被跳过的 lazy 标签标记 `retainedKeys`（原副本即用户要求保留的内容）；`StagedRecord.content` 改可空（undefined=未知内容），`onDocumentSaved` 对未知内容**不删**（只删确认被保存覆盖的副本）；`cleanupResolvedCopies` 跳过未加载标签。
- `saveDocument.ts`：保存前遇 lazy 标签先 `loadRestoredTab`（正文加载后再保存，绝不写空占位）。
- 既有测试适配 R01 新语义（命名恢复不脏/未命名 staged 恢复脏/正文 null），断言含正文字段本身。

### R02 Markdown pending 丢历史组 ✅
- **按复审允许的方式回退 J2 合并序列化**：`VisualKernel.tsx` onUpdate 恢复每键即时 serialize+record（分组、选区、脏态语义与原实现一致）；删除单槽 pendingChangeRef/commitPendingVisualChange/visualPendingChanges 全套机制；Markdown capability flush 不再无条件冲刷（源码模式不触碰 visual 模型）。
- 修复过程中发现并恢复被误删的 `editorProps`（图片粘贴/拖放），R02 重写时的功能回归已补回。
- 反例"500ms 内两个原生历史组保留中间节点"通过；进度文档中 S13/J2 状态改为"已按复审回退"。

### R03 陈旧 flush 覆盖新内容 ✅
- `documentSession.ts` 新增 `submitCapturedContent` 统一提交屏障：**实例代际不匹配（旧实例迟到）或 revision 已前进（有更新输入）的快照一律丢弃**；全部编辑器 adapter（code/markdown/board/split）与 `syncDocumentContent` 的镜像写入改经此屏障（不再各自直写）。
- `queuedAutoSave` 写任务执行时**重新验证生命周期**（文档存在/策略仍 auto/外部状态未变——排队期间切手动策略或文件被删的旧任务不落盘）。
- 反例"旧实例 flush 晚到"通过（旧内容不再覆盖新实例已同步内容）。

### R04 关闭后重开失效 ✅
- `windowStore.ts`：closeTab/confirmCloseBatch/closeOtherTabs/closeTabsLeft/closeTabsRight/closeAllTabs 全部关闭路径统一 `disposeTabLifecycle`（注销 Rust 归属 + markClosed + disposeDocumentSession，fire-and-forget 幂等）。
- Rust `prepare.rs`：在途 pending 的双重检查**读取真实在途发起者**（不冒充 self）。
- `openDocument.ts`：already-open(self) 但标签不存在时小重试（5×60ms）等待注销/首请求完成，仍失败则受限递归重新完整打开（深度≤2）。
- 反例"关闭干净标签后立即重开"通过。

### R05 回收误卸载不可回收编辑器 ✅
- `AppShell.tsx` 收敛逻辑重写：**逐项授权**——对每个非活动/非保活的挂载标签单独 `suspendEditorInstance`，只有明确通过（canSuspend+flush+版本校验）才移出渲染集合；不可回收类型保留（pinned），不被其它项的成功驱逐带走；收敛使用 ref 镜像的最新集合与最新 activeKey（不依赖过期闭包）。
- `code editorCapabilities`：canSuspend 增加 `!view.composing`（IME 组合中不回收）。

### R06 迁移协议 ✅
- 源：载荷携带**真实 viewState**（captureViewState）与**可序列化统一历史**（新增 serializeDocumentHistory/restoreDocumentHistory，检查点+补丁链整体迁移）；进入迁移保护后**主动 blur**（pointerEvents 不挡已聚焦编辑器的键盘/IME）。
- 超时（30s）：**先查询后端权威状态**——committed→按成功；preparing/target-prepared→主动 CAS abort（后端拒绝已提交）；查询失败→保守失败（源保留标签）。
- 目标 prepare IPC 失败：**先查询状态**（committed→保留解锁；aborted→清理；未知→保留不删）。
- Rust `take_transfer_payload`：破坏性 take → **非破坏 peek**（接纳途中失败/重载可重取；committed/aborted 时清空）。

### R07 队列分页与退出 ✅
- `runDrain` 重写：处理完非空页**主动续拉**（一次唤醒拉完分页，不依赖新事件）；空页只有无新事件才退出（覆盖"刚收到空列表又来事件"竞态）；ACK 失败受控重试一次（仍失败下次 drain 重拉该请求）。
- Rust `close_window`：最后窗口退出前把**本窗口未处理请求并入待分配队列**（不被 app.exit 丢弃）。

### R08 协调器重挂载 ✅
- `acquireBootCoordinator`：disposed 后再 acquire 允许重新初始化（重建监听+新握手；StrictMode unmount→remount 覆盖）。
- App 启动顺序修正：**先监听/握手（initWindow）再加载设置**（数据保护先于一切，与注释声明一致）。
- 错误壳：尽力调用 `windowShellReady` 显示窗口（初始 visible=false 不再永远隐藏）；重试改为**重跑初始化**（非整页 reload——不绕过未保存保护），并新增安全关闭按钮。

### R09 watcher 端到端 ✅
- `directoryWatcher.ts`：事件回调**直连刷新链**（readDir + updateChildren，与 Explorer 同一 store 路径——不再 mitt/Tauri 双总线脱节）。
- 自身写入静默：命中静默窗口不再直接丢弃——**登记待复核目录**，静默窗口结束后统一复核刷新（其它软件紧随其后的修改不被吞）。
- unwatch 竞态：归零后重查引用计数与记录代际（等待期间的新订阅不误停）。

### R10 编辑器重试 ✅
- `EditorHost`：ErrorBoundary 使用真正的 React `key={retryGeneration}`（重试强制重建边界，退出 hasError 状态）。
- `prefetchEditor`：失败捕获（未处理 rejection 清除；失败不清模块缓存，渲染时由错误边界呈现重试）。

### R11 字体门槛与代际 ✅
- **真正解耦**：`settingsStore.init` 不再 Promise.all 等待字体 init（fire-and-forget）；App 渲染只等 `initialized`（不等 fontPackInitialized）。
- **按具体 face**：ensureFaces 只主动加载引用族的 **400 normal**（正文默认）；粗体/斜体由 CSS 使用时触发（display:swap）。过滤改用平行描述符数组（不依赖 FontFace 实例属性的可移植性）。
- Rust `pending_rerun`：验证进行中 refresh 递增 generation → 旧任务结束时**接续最新验证**（前端不再停在 verifying）。
- 前端 `packEpoch`：异步激活完成时 epoch 已变（remove/import）→ 旧 ready 结果丢弃（不覆盖新 invalid/missing 状态）。

### R12 saveAs 与关闭保护 ✅
- saveAs：目标被**其它窗口**占用时中止（提示，不先覆盖再检查）；对话框/写盘期间新编辑不丢——完成后重新 flush 旧 key，内容不同则**补写新 key 并保持 dirty**。
- `performWindowClose`：顺序修正为**先排空写队列再注销所有权**（原顺序注销期间新窗口可能取得文档而旧窗口仍在写）。
- "保存并关闭"：saveDocument 成功后**检查仍脏则不静默关闭**（提示再次保存）。

### R13 暂存签名与资源清理 ✅
- 暂存队列签名改用**真实每文档 revision**（editorRegistry）+ 脏态——等长替换（revision 递增）不再漏检；windowStore 订阅保留为结构变化兜底。
