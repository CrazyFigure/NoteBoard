## 1. 共享 DTO

### 1.1 基础值类型

```ts
// src/core/ipc/types.ts

export type ThemeMode    = ThemeId | 'system';

```

```rust
// src-tauri/src/dto.rs
#[derive(Serialize, Deserialize, Clone, Copy, PartialEq, Eq, Debug)]
#[serde(rename_all = "kebab-case")]
pub enum DocumentKind { Markdown, Code, Board, Unsupported }

#[derive(Serialize, Deserialize, Clone, Copy, PartialEq, Eq, Debug)]
#[serde(rename_all = "kebab-case")]

#[derive(Serialize, Deserialize, Clone, Copy, PartialEq, Eq, Debug)]
#[serde(rename_all = "kebab-case")]

```

> **序列化约定**：Rust 侧全部用 `#[serde(rename_all = "camelCase")]`（结构体字段）与 `kebab-case`（枚举变体），与 TS 命名习惯对齐。

### 1.2 文档载荷

```ts
export interface DocumentPayload {
  key: string;              // 规范化绝对路径
  displayName: string;      // 文件名含扩展名
  dirPath: string;          // 父目录绝对路径
  kind: DocumentKind;
  language: LanguageId;
  /** kind !== 'unsupported' 时为文件文本内容；board 也是文本（JSON 原文） */
  content: string | null;
  encoding: Encoding;
  eol: Eol;
  size: number;             // 字节
  mtime: number;            // Unix 毫秒
  readonly: boolean;        // 文件系统只读属性
}

export interface WriteResult {
  ok: boolean;
  mtime: number;            // 写入后的新 mtime，前端用它更新基线
  size: number;
  error: WriteError | null;
}

export type WriteError =
  | { kind: 'permission-denied'; path: string }
  | { kind: 'disk-full' }
  | { kind: 'file-locked'; path: string }
  | { kind: 'readonly'; path: string }
  | { kind: 'path-not-found'; path: string }
  | { kind: 'io'; message: string };
```

> **`WriteError` 是可辨识联合而非字符串** —— 前端要根据类型给不同的提示与补救动作（如 `readonly` 提示「取消只读属性后重试」，`file-locked` 提示「文件可能被其他程序占用」）。

```rust
#[tauri::command]
async fn create_window(
    app: tauri::AppHandle,
    state: tauri::State<'_, Mutex<AppState>>,
    intent: WindowIntent,
) -> Result<CreateWindowResponse, String> {
    let label = {
        let mut s = state.lock().unwrap();          // 🔴 持锁范围必须短，不跨 await
        let label = format!("nb-{}", s.next_window_seq);
        s.next_window_seq += 1;
        s.intents.insert(label.clone(), intent);
        label
    };                                              // 锁在此释放

    let handle = app.clone();
    let l = label.clone();
    // 🔴 必须切线程：WebviewWindowBuilder::build() 在同步上下文中会死锁（wry#583）
    std::thread::spawn(move || {
        let _ = tauri::WebviewWindowBuilder::new(&handle, &l,
                    tauri::WebviewUrl::App("index.html".into()))
            .title("NoteBoard")
            .inner_size(1200.0, 800.0)
            .decorations(false)          // 自绘标题栏
            .visible(false)              // 前端就绪后 show()，防白屏
            .shadow(true)
            .build();
    });

    Ok(CreateWindowResponse { label })
}
```

**原子写实现**（`fsio/write.rs`）：

```rust
pub fn atomic_write(path: &Path, bytes: &[u8]) -> Result<(), WriteError> {
    let dir = path.parent().ok_or(WriteError::PathNotFound)?;
    // ① 临时文件必须与目标同目录 —— 跨卷 rename 不是原子操作
    let mut tmp = tempfile::Builder::new()
        .prefix(".nb-tmp-")
        .tempfile_in(dir)?;
    tmp.write_all(bytes)?;
    tmp.as_file().sync_all()?;              // ② 落盘
    tmp.persist(path)?;                     // ③ rename 覆盖（NTFS 同目录原子）
    Ok(())
}
```

## 3. 事件契约

事件名统一前缀 `nb://`。载荷全部是对象（不用裸值，便于将来加字段）。

| 事件 | 投递 | 载荷 |
|---|---|---|
| `nb://open-files` | `emit_to(label)` | `{ paths: string[] }` |
| `nb://focus-tab` | `emit_to(label)` | `{ key: string }` |
| `nb://external-change` | `emit_to(owner)` | `{ key, changeType: 'modified'\|'deleted'\|'renamed', mtime, size, newPath?: string }` |
| `nb://explorer-refresh` | `emit_to(label)` | `{ dir: string }` |
| `nb://explorer-rescan` | `emit_to(label)` | `{ root: string }` |
| `nb://settings-changed` | **`emit` 广播** | `Settings`（全量 + `revision`） |
| `nb://before-quit` | **`emit` 广播** | `{}` |
| `nb://handoff-complete` | `emit_to(sourceLabel)` | `{ targetLabel, keys: string[] }` |

> 🔴 **Tauri v2 陷阱**：在 `Window` / `WebviewWindow` 实例上调 `.emit()` **也是广播**（与 v1 相反）。定向必须显式 `emit_to(label, ...)`。**这是 code review 的必查项。**

前端侧封装：

```ts
// src/core/ipc/events.ts —— 组件只用这些，不直接 listen

export function onExternalChange(cb: (p: ExternalChangePayload) => void): Promise<UnlistenFn>;
export function onSettingsChanged(cb: (s: Settings) => void): Promise<UnlistenFn>;
// …
```

## 4. 持久化文件格式

全部位于 `%APPDATA%\NoteBoard\`。写入一律走 §2.3 的原子写路径。

### 4.1 `settings.json`

```jsonc
{
  "schemaVersion": 1,
  "revision": 42,                       // 单调递增，用于广播去重

  "appearance": {
    "themeMode": "hu-po",               // ThemeId | 'system'
    "systemLightTheme": "chen-guang",
    "systemDarkTheme": "mo-ye"
  },

  "typography": {
    "contentFontFamily": "",            // "" = 系统默认
    "monoFontFamily": "Consolas",
    "contentFontSize": 16,              // 12–24
    "monoFontSize": 14,                 // 12–22
    "contentLineHeight": 1.7,           // 1.0–3.0
    "contentWidth": "standard"          // narrow | standard | wide | full
  },

  "editor": {
    "defaultViewMode": "visual",
    "softWrap": true,
    "showLineNumbers": true,
    "showIndentGuides": true,
    "tabSize": 2,
    "insertSpaces": true,
    "enableMath": true,
    "enableMermaid": true,
    "enableAlerts": true,
    "enableBlockHandle": true
  },

  "file": {
    "forceManualSave": false,           // FR-1208：true 时全部改为手动保存
    "showHiddenFiles": false,
    "restoreSession": true,             // FR-612
    "imageDirName": "assets",           // FR-313
    "largeFileConfirmMb": 50            // FR-113
  },

  "layout": {
    "statusBarVisible": true,
    "uiScale": 100                      // 75–150
  }
}
```

**读取容错**：任一字段缺失或类型不符 → 用默认值填充该字段，**不整体丢弃**。整个文件解析失败 → 重命名为 `settings.corrupt-{ts}.json`，用全默认值启动，在「关于」页标记告警。

### 4.2 `session.json`

```jsonc
{
  "schemaVersion": 1,
  "savedAt": 1755403200000,
  "windows": [
    {
      "seq": 1,
      "bounds": { "x": 100, "y": 100, "width": 1200, "height": 800, "maximized": false },
      "explorerRoot": "D:\\notes\\2026",
      "layout": {
        "explorerVisible": true,  "explorerWidth": 260,
        "outlineVisible": true,   "outlineWidth": 280
      },
      "tabs": [
        { "key": "D:\\notes\\2026\\待办.md",  "isPinned": true,  "viewMode": "visual" },
        { "key": "C:\\project\\sql\\schema.sql", "isPinned": true, "viewMode": null }
      ],
      "activeKey": "D:\\notes\\2026\\待办.md"
    }
  ]
}
```

**恢复时的容错**：文件已不存在的 tab **静默跳过**（不弹错误 —— 用户可能只是移动了文件）；某个窗口的全部 tab 都失效则仍恢复该窗口但显示欢迎页；`explorerRoot` 不存在则回退到用户主目录。

**不存内容**，只存路径。会话恢复靠重新读盘。未保存内容的恢复走草稿机制（§4.4）。

### 4.3 `recent.json`

```jsonc
{
  "schemaVersion": 1,
  "files": [
    { "path": "D:\\notes\\2026\\待办.md", "openedAt": 1755403100000 }
  ],
  "dirs": [
    { "path": "D:\\notes\\2026", "openedAt": 1755403000000 }
  ]
}
```

各上限 30 条，按 `openedAt` 倒序，超出截断。

### 4.4 `drafts/{sha256(key)}.json`

```jsonc
{
  "schemaVersion": 1,
  "key": "C:\\project\\sql\\schema.sql",
  "kind": "code",
  "content": "SELECT …",
  "savedAt": 1755403180000,
  "diskMtimeWhenOpened": 1755400000000
}
```

| 规则 | 说明 |
|---|---|
| 文件名 | `sha256(小写规范化 key)`，避免路径非法字符与长度限制 |
| 写入时机 | 脏文档每 10 秒 + 编辑器失焦 |
| 删除时机 | 该文档正常保存成功后立即删 |
| 启动扫描 | 目录非空 → 提示「上次异常退出，有 N 个未保存的文件」，逐个提供 查看差异 / 恢复 / 丢弃 |
| 清理 | 启动时删除 `savedAt` 超过 7 天的孤儿草稿 |

> `diskMtimeWhenOpened` 用于恢复时判断磁盘文件在这期间是否也变了 —— 若变了，恢复时要提示可能冲突。

### 4.5 `window-state.json`

由 `tauri-plugin-window-state` 完全托管，**不手动读写**。

> 注意与 `session.json` 的 `bounds` 有职责重叠。**分工**：插件负责「窗口在哪」（OS 层面，含最大化/多屏），`session.json` 的 `bounds` 仅作为插件不可用时的兜底，恢复时**以插件为准**。

前端 TS 与 Rust 的类型手工同步，必须有测试兜住。

### 5.1 枚举一致性

```rust
{
```

```ts
  expect(ALL_DOCUMENT_KINDS).toEqual(rust.DocumentKind);
  expect(ALL_ENCODINGS).toEqual(rust.Encoding);
  // …
});
```

### 5.2 扩展名映射一致性

`KIND_BY_EXT` 是单一真相源。Rust 侧从同一份 JSON 生成：

```
src/core/docKind.json      ← 唯一真相源
   ├─ src/core/docKind.ts   （import 这份 JSON）
   └─ src-tauri/build.rs    （include_str! 这份 JSON，生成 Rust 静态表）
```

```ts
test('扩展名映射覆盖全部点名格式', () => {
  for (const ext of ['md','markdown','txt','sql','json','yaml','yml','xml','excalidraw']) {
    expect(KIND_BY_EXT[ext]).toBeDefined();
  }
});

test('每个 kind 的 savePolicy 推导正确', () => {
  expect(savePolicyOf('markdown')).toBe('auto');
  expect(savePolicyOf('board')).toBe('auto');
  expect(savePolicyOf('code')).toBe('manual');
});
```

### 5.3 命令签名冒烟测试

每个命令都有一条最小往返测试（在 Tauri 集成测试环境中跑），断言参数能被 Rust 正确反序列化、返回值能被 TS 正确解析。这类测试廉价但能挡住绝大多数字段名拼写错误（`camelCase` / `snake_case` 不匹配是最常见的坑）。

### 5.4 配置文件向后兼容

```ts
test('缺字段的旧 settings.json 能被正确填充默认值', () => {
  const partial = { schemaVersion: 1, appearance: { themeMode: 'hu-po' } };
  const merged = mergeSettings(partial);
  expect(merged.typography.contentFontSize).toBe(16);
  expect(merged.appearance.themeMode).toBe('hu-po');
});

test('损坏的 JSON 不导致崩溃', () => {

});
```

## 6. 版本演进规则

| 规则 | 说明 |
|---|---|
| 所有持久化文件都有 `schemaVersion` | 当前全部为 `1` |
| **加字段** | 不升版本，读取端用默认值填充 |
| **删字段** | 不升版本，读取端忽略未知字段 |
| **改字段语义或类型** | **升版本**，并写迁移函数 `migrate_v1_to_v2` |
| 遇到**更高**的 `schemaVersion` | 不解析，重命名备份，用默认值启动，并提示「配置来自更新版本的 NoteBoard」 |
| IPC 命令 | 新增用新命令名，不改既有命令的参数含义 |
| 事件载荷 | 只加字段不删字段 |
