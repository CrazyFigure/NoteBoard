## 2. 自绘标题栏

```
┌────────────────────────────────────────────────────────────────────────────┐
│  ▣  ┌─────────────────┬──────────────────┬─────────────┐   ░░░░░   ─ □ ✕  │
│ 16px│ ● 待办.md     ✕ │ 📄 schema.sql  ✕ │ 🎨 架构图 ✕ │  拖拽区   46px×3  │
│     └─────────────────┴──────────────────┴─────────────┘                  │
└────────────────────────────────────────────────────────────────────────────┘
  ↑                                                          ↑
  应用图标（logo.ico 16×16）                       data-tauri-drag-region
  也是 data-tauri-drag-region                      （只加在这块空白 div 上）
```

### 2.1 拖拽区的关键约束

`data-tauri-drag-region` **只作用于直接标注的元素，不继承给子元素**（Tauri 官方文档明确说明）。

**因此**：

- ✅ 只给 tab 栏**右侧的空白 div** 与**应用图标**加这个属性
- ❌ **不要**给 tab 栏容器加 —— 否则 tab 本身仍可点（属性不继承），但语义混乱
- ❌ **不要**给窗口控制按钮加

Windows 触摸/手写笔支持需补 CSS：

```css
*[data-tauri-drag-region] { app-region: drag; }
```

双击拖拽区 → `toggleMaximize()`。

### 2.2 窗口控制按钮

| 按钮 | 尺寸 | 悬停背景 | 图标 |
|---|---|---|---|
| 最小化 | `46×36` | `--toolbar-hover` | `lucide:minus` |
| 最大化/还原 | `46×36` | `--toolbar-hover` | `lucide:square` / `lucide:copy` |
| 关闭 | `46×36` | `#e81123`（Windows 标准红），图标转白 | `lucide:x` |

## 3. Tab

### 3.1 单个 Tab 结构

```
┌──────────────────────────────────┐
│ ●  📄  待办.md                ✕  │  高度 36px（撑满标题栏）
└──────────────────────────────────┘
  ↑   ↑    ↑                    ↑
  │   │    文件名（最大 160px，   关闭按钮（12px 图标）
  │   │    超出则末端省略号）      平时隐藏，悬停 tab 时显现
  │   类型图标 14px               激活 tab 恒显
  未保存圆点 6px（--tab-dirty-dot）
  仅手动保存类且脏时显示
```

宽度：`min 120px`，`max 200px`，内容自适应。数量过多时 tab 栏横向滚动（滚轮横滚），**不做多行**。

### 3.2 类型图标与颜色

| 扩展名 | 图标（lucide） | 颜色 |
|---|---|---|
| `.md` `.markdown` | `file-text` | `--editor-accent` |
| `.txt` `.log` | `file` | `--editor-text-muted` |
| `.sql` | `database` | `#8250df` / 暗色 `#a371f7` |
| `.json` | `braces` | `--warning-600` |
| `.yaml` `.yml` | `file-code` | `--success-600` |
| `.xml` | `code-xml` | `#0969da` / 暗色 `#4493f8` |
| `.excalidraw` | `pencil-ruler` | `--accent-strong` |
| 其他 | `file-question` | `--editor-text-muted` |

### 3.3 状态视觉

| 状态 | 背景 | 顶部指示条 | 文字 |
|---|---|---|---|
| 激活 | `--tab-active-bg` | `2px solid --tab-active-indicator` | `--editor-text` |
| 未激活 | `--tab-inactive-bg` | 无 | `--editor-text-secondary` |
| 悬停（未激活） | `--tab-hover-bg` | 无 | `--editor-text` |
| 预览态（单击树节点打开） | 同未激活 | 无 | **斜体** |
| 外部变更 | 同当前 | 无 | 图标换 `alert-triangle`，色 `--warning-600` |
| 已断开（文件被删） | 同当前 | 无 | 图标换 `unlink`，色 `--error-500` |

### 3.4 拖拽排序（FR-604）

**必须用 dnd-kit 的 `PointerSensor`。禁止 HTML5 DnD 与 `react-dnd` 的 `HTML5Backend`**（原因见 [ADR-014](05-ADR/ADR-014-拖放机制取舍.md)）。

```
拖拽中：
┌──────────┬╌╌╌╌╌╌╌╌╌╌┬──────────┐
│ 待办.md  │ ▓ 拖拽中  │ 架构图   │
└──────────┴╌╌╌╌╌╌╌╌╌╌┴──────────┘
             ↑ 半透明 0.5，跟随指针
                    ┃
                    ┗━ 2px 竖线插入指示（--accent-strong）
```

配置：`activationConstraint: { distance: 5 }`（避免与点击冲突）。

### 3.5 Tab 右键菜单（FR-605）

## 4. 折叠把手（RailToggle）

用户原话：「在编辑区左侧中间放一个悬浮隐藏的一个箭头按钮」。

### 4.1 位置与尺寸

```
编辑区左边缘                                     编辑区右边缘
      ┃                                               ┃
      ┃                                               ┃
   ┌──┃──┐  ← 垂直居中                          ┌──┃──┐
   │ ◀ ┃  │     宽 14px / 高 48px                │  ┃ ▶│
   └──┃──┘     圆角：右侧 6px（左把手）          └──┃──┘
      ┃                                               ┃
```

| 属性 | 值 |
|---|---|
| 尺寸 | `20 × 56px` |
| 垂直位置 | 编辑区高度 50%，`transform: translateY(-50%)` |
| 水平位置 | 左把手贴编辑区左边缘（`left: 0`）；右把手贴右边缘（`right: 0`） |
| 圆角 | 左把手 `0 8px 8px 0`；右把手 `8px 0 0 8px` |
| 图标 | `lucide:chevron-left` / `chevron-right`，`16px` |
| `z-index` | `20`（在编辑器内容之上，在浮层菜单之下） |

### 4.2 悬浮隐藏交互（关键细节）

```
默认态          鼠标进入编辑区 100px 内          鼠标悬停把手上
opacity: 0      opacity: 0.75                  opacity: 1
无背景          背景 --rail-bg                  背景 --rail-hover-bg
                边框 --editor-border            边框 --editor-border-focus
                图标色 --rail-fg                图标色 --editor-text
```

- 过渡：`opacity var(--transition-normal)`, `background var(--transition-fast)`, `border-color var(--transition-fast)`, `box-shadow var(--transition-fast)`
- **触发区**是把手周围 `100 × 140px` 的不可见热区（比把手本身大，方便快速唤出）
- `opacity: 0` 时仍保留 `pointer-events: auto`，保证键盘可聚焦
- **键盘可达**：`Tab` 能聚焦到把手，`Enter`/`Space` 触发；聚焦时 `opacity: 1` + 焦点环

### 4.3 方向语义

| 面板状态 | 左把手图标 | 右把手图标 |
|---|---|---|
| 展开 | `◀`（点击收起） | `▶`（点击收起） |
| 收起 | `▶`（点击展开） | `◀`（点击展开） |

**箭头始终指向「点击后面板会移动的方向」。**

面板收起后，把手贴在窗口边缘（编辑区此时占满），保持同样的悬浮隐藏行为。

## 5. 资源管理器

```
┌──────────────────────────────┐
│ 资源管理器            ⟳  ⋯   │ 28px  标题行
│ D:\notes\…\2026              │ 22px  当前根路径（纯展示，不可点）
├──────────────────────────────┤
│ ▾ 📂 素材                    │ 24px/行
│ │   📄 参考.md                │
│ ▸ 📂 归档                     │
│   📄 日记.md                  │
│ ▌ 📄 待办.md                 │ ← 当前 tab，左侧 2px 竖条 + 高亮背景
│   📄 周报.md                  │
│   🎨 架构图.excalidraw         │
└──────────────────────────────┘
```

### 5.1 行规格

| 属性 | 值 |
|---|---|
| 行高 | `24px` |
| 缩进 | `paddingLeft = depth * 12 + 8` px |
| 缩进导线 | `1px solid --explorer-indent-guide`，每级一条 |
| 展开箭头 | `12px`，`lucide:chevron-right` 旋转 90° |
| 文件图标 | `14px`，同 §3.2 |
| 文字 | `13px`，色 `--explorer-text` |
| 悬停 | 背景 `--explorer-hover` |
| 当前 tab | 背景 `--explorer-active` + 左侧 `2px solid --accent-strong` |

### 5.2 根路径显示（FR-712）

- 过长时**中间省略**：`D:\notes\…\2026`（保留盘符与最后一级）
- 悬停显示完整路径的 tooltip
- **纯展示，不可点击**（[ADR-007](05-ADR/ADR-007-资源管理器语义.md)：不做面包屑跳转，避免让「纯跟随」规则含糊）

### 5.3 排序（FR-704）

1. 目录在前，文件在后
2. 各自按名称**自然排序**（数字按数值比较：`file2.md` < `file10.md`）
3. 大小写不敏感

### 5.4 右键菜单（FR-706）

**目录节点**：
```
新建文件…          │ 新建文件夹…
──────────────────┤
重命名          F2 │ 删除（到回收站）  Del
──────────────────┤
复制完整路径       │ 在资源管理器中显示
──────────────────┤
设为资源管理器根    │  ← 等价于「打开文件夹」
```

**文件节点**：
```
打开               │ 在新窗口中打开
──────────────────┤
重命名          F2 │ 删除（到回收站）  Del
──────────────────┤
复制完整路径       │ 复制文件名
──────────────────┤
在资源管理器中显示  │ 用系统默认程序打开
```

### 5.5 打开语义：预览态 tab

| 操作 | 行为 |
|---|---|
| **单击**文件 | 打开为**预览态** tab（标题斜体）。再单击另一个文件 → **复用**同一个 tab 位 |
| **双击**文件 | 打开为固定 tab |
| 预览态 tab 内发生编辑 | 自动转为固定 |
| 预览态 tab 被双击 | 转为固定 |

这套语义与 VSCode 一致，避免浏览目录时堆一屏 tab。

## 6. Markdown 编辑器

### 6.1 块把手（BlockHandle，FR-311）

用户原话：「行前八个点拖动排序」。

```
        ┌────────────────────────────────────
   ⠿    │ 这是一个段落，鼠标移到这一行时左侧
        │ 浮出六点手柄。
        └────────────────────────────────────
   ↑
   14×20px，位于内容左侧 -32px 处
   （所以 .ProseMirror 的 padding-left 必须 ≥ 48px）
```

| 属性 | 值 |
|---|---|
| 图标 | `lucide:grip-vertical`（2×3 点阵） |
| 尺寸 | `14 × 20px` |
| 位置 | 当前悬停块的左侧 `-32px`，垂直对齐块首行 |
| 默认 | `opacity: 0` |
| 悬停块内任意处 | `opacity: 0.4` |
| 悬停手柄本身 | `opacity: 1` + 背景 `--toolbar-hover` + `cursor: grab` |
| 拖拽中 | `cursor: grabbing`，落点显示 `2px` 横线（`--accent-strong`） |

**实现**：`@tiptap/extension-drag-handle` + `@tiptap/extension-node-range`（必装 peer）。
**这条需求强制 `dragDropEnabled: false`**，见 [ADR-014](05-ADR/ADR-014-拖放机制取舍.md)。

### 6.2 斜杠命令（FR-309）

输入 `/` 触发。支持中英文关键词搜索（`/表格` 与 `/table` 都能命中）。

```
┌───────────────────────────────────┐
│ 基础                              │
│  H1  一级标题          # + 空格    │
│  H2  二级标题          ## + 空格   │
│  ≡   无序列表          - + 空格    │
│  1.  有序列表          1. + 空格   │
│  ☑   任务列表          - [ ]       │
│  "   引用              > + 空格    │
│  ─   分割线            ---         │
│ 块                                │
│  ⌗   代码块            ```         │
│  ⊞   表格              Ctrl+M      │
│  Σ   数学公式块        $$          │
│  ◇   Mermaid 图表                  │
│ 提示块                             │
│  ℹ   注释 NOTE                     │
│  ✓   提示 TIP                      │
│  ★   重要 IMPORTANT                │
│  ⚠   警告 WARNING                  │
│  ⛔  危险 CAUTION                   │
└───────────────────────────────────┘
```

`↑↓` 导航，`Enter` 确认，`Esc` 关闭。最多显示 8 项，超出滚动。

### 6.3 选中浮层菜单（FR-310）

```
        ┌──────────────────────────────────────────┐
        │ B  I  S  <>  🔗 │ H1 H2 H3 │ 🖍 │  ⋯    │  32px
        └──────────────────────────────────────────┘
                    ▼ 8px 间距
        ┏━━━━━━━━━━━━━━━━━━━┓
        ┃ 被选中的这段文字   ┃
        ┗━━━━━━━━━━━━━━━━━━━┛
```

出现在选区上方 8px；空间不足时翻到下方。选区为空或失焦时消失。

### 6.4 代码块

```
┌────────────────────────────────────────────────┐
│ TypeScript ▾                          📋 复制  │ 28px  头部（悬停时显现）
├────────────────────────────────────────────────┤
│ const a = 1;                                   │
│ function f() { return a; }                     │
└────────────────────────────────────────────────┘
  背景 --code-block-bg，边框 1px --editor-border，圆角 6px
```

语言下拉支持搜索。列表为 highlight.js 的 `common` 语言集（约 37 种）+ `自动检测` + `纯文本`。

> 注意：代码块内的高亮走 lowlight（highlight.js 的 37 种），这与[代码**文件**只支持 5 种语言](05-ADR/ADR-004-代码类文件的语言支持范围.md)是两件不同的事——代码块高亮不需要语法树，成本低得多。

### 6.5 视图模式切换（FR-301）

状态栏右侧的切换按钮 + `Ctrl+/`：

```
┌─────────────┬─────────────┐
│ ✦ 所见即所得 │   源码      │     激活项背景 --toolbar-active
└─────────────┴─────────────┘
```

切换时保留光标与滚动位置（FR-303）。

### 6.6 大文档横幅（NFR-201）

```
┌────────────────────────────────────────────────────────────────────┐
│ ⓘ 这是一个大文档（324,180 字符），已用源码模式打开以保证流畅。       │
│                                        〔仍要使用可视化编辑〕  ✕   │
└────────────────────────────────────────────────────────────────────┘
```

背景 `--alert-note-bg`，左边框 `3px solid --alert-note-border`。

点击「仍要使用可视化编辑」→ 进入分段虚拟滚动模式，横幅变为：

```
┌────────────────────────────────────────────────────────────────────┐
│ ⓘ 分段编辑模式：不支持跨段选择与跨段拖拽块。          〔切回源码〕  │
└────────────────────────────────────────────────────────────────────┘
```

| 字号 | h1 `13px/600`；h2 `13px/500`；h3+ `12px/400` |
| 当前项 | 背景 `--outline-item-active-bg` + 文字 `--outline-item-active-text` + 左侧 `2px solid --accent-strong` |
| 悬停 | 背景 `--outline-item-hover-bg` |
| 折叠 | 仅 h2 / h3 可折叠 |

### 7.1 双向滚动同步（FR-903）

| 方向 | 触发 | 防抖 | 逻辑 |
|---|---|---|---|
| 编辑区 → 大纲 | `selectionUpdate` | 100ms | 取满足 `heading.pos <= cursorPos` 的最后一个 |
| 编辑区 → 大纲 | 滚动容器 `scroll`（`passive: true`） | 50ms | 取 `offsetTop <= scrollTop + 40` 的最后一个 |
| 大纲 → 编辑区 | 点击条目 | 无 | `focus()` → `setTextSelection(pos+1)` → `scrollIntoView({behavior:'smooth', block:'start'})` |

大纲面板自身跟随：当前项变化时 `activeElement.scrollIntoView({ behavior: 'smooth', block: 'nearest' })`。

## 12. 动效规范

| 场景 | 时长 | 曲线 | 属性 |
|---|---|---|---|
| 折叠把手显隐 | `200ms` | `ease` | `opacity` |
| 面板展开/收起 | `200ms` | `ease` | `width` |
| Tab 切换 | 无动画 | — | 立即（NFR-105 ≤ 150ms） |
| 主题切换 | 无动画 | — | 立即（避免中间态色彩闪烁） |
| 悬停反馈 | `150ms` | `ease` | `background` |
| 对话框出现 | `150ms` | `ease-out` | `opacity` + `scale(0.98→1)` |
| 大纲滚动跟随 | `smooth` | 浏览器默认 | `scrollIntoView` |
| 拖拽指示线 | 无动画 | — | 立即 |

**遵循 `prefers-reduced-motion`**：命中时全部动效时长归零，`scrollIntoView` 改 `behavior: 'auto'`。

## 13. 无障碍要点（NFR-403）

| 项 | 要求 |
|---|---|
| 焦点环 | `2px solid var(--editor-border-focus)` + `outline-offset: 2px`，全局统一 |
| Tab 序 | 标题栏 → tab 栏 → 左把手 → 资源管理器 → 编辑区 → 右把手 → 大纲 → 状态栏 |
| 折叠把手 | 可聚焦，`aria-expanded`，`aria-label="展开/收起资源管理器"` |
| Tab 栏 | `role="tablist"`，每个 tab `role="tab"` + `aria-selected` |
| 资源管理器 | `role="tree"`，节点 `role="treeitem"` + `aria-expanded` + `aria-level` |
| 大纲 | 同上 |
| 对话框 | `role="dialog"` + `aria-modal="true"`，焦点陷阱，`Esc` 关闭 |
| 未保存圆点 | 不能只靠颜色 —— 同时有标题栏 `*` 与状态栏「未保存」文字 |
| 图标按钮 | 全部有 `aria-label` |
